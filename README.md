# SF2 Tactical Prototype

在瀏覽器裡玩的戰術 FPS，靈感來自《特種部隊 2》。可以單人對戰 AI Bot，也可以加好友、邀請朋友連線對戰（所有模式都能連線）。有 7 張地圖和 31 把槍，支援團隊死鬥、回合殲滅、奪取、佔領等模式。

## ▶ 線上試玩

**https://weiweiweiweiweiweiweiwei.github.io/sf2-tactical-prototype/**

打開網址 → 在大廳按「建立房間」→ 選地圖、人數、模式 → 按「出發」→ 點畫面鎖定滑鼠就能開始。

## 和朋友連線對戰

打開遊戲會先到**大廳**。

**開房間的人：**
1. 在大廳右上角輸入暱稱，按「建立房間」。房間一建立就有 6 位數代碼。
2. 按房間上方的「＋ 邀請朋友」：複製邀請連結，或把 6 位數代碼告訴朋友。
3. 朋友進來後會出現在隊伍名單上。選好地圖和賽制（四種都可以連線），大家到齊後按「出發」。

**加入的人**，三種方式都可以：
- 直接點邀請連結。
- 在大廳按「加入房間」，輸入 6 位數代碼（也可以直接貼上整段連結）。
- 房主勾了「公開到大廳的房間列表」的話，從大廳右側的列表按「加入」。

說明：

- **打完會回到同一個房間**，可以直接再開下一場。
- **在房間裡可以換隊**（按「換到紅隊／藍隊」）和改自己的配裝；地圖、模式和 Bot 人數由房主設定。
- **對戰不會暫停**：連線中按 ESC 或切到別的視窗，對戰都照常進行。
- **房主離開房間，由最早進房的朋友接手**，房間代碼不變；房主在對戰中離開的話，那一場會結束，大家回到房間。
- **大部分家用網路可以直接連**：部分手機熱點、公司或學校網路會擋直連，這時會顯示「無法和房主建立直接連線」，換個網路再試。
- **有延遲補償**：打移動中的人不用提前量，瞄準畫面上看到的位置就會命中。
- **最多 8 人**。手榴彈和掉槍還沒同步（連線中撿不到地上的槍）。

自己想先測試的話：同一個瀏覽器開兩個分頁，一個建立房間，另一個在大廳輸入代碼加入即可。

### 好友

按大廳或房間右上角的「👥 好友」：

- **加好友**：把「我的好友代碼」（8 位數）傳給朋友，對方在他的好友面板輸入後按「加好友」，你這邊接受就成為好友。不用註冊帳號。
- **看上線狀態**：好友名單會顯示在大廳、在哪個房間、對戰中或離線。
- **邀請**：在房間按「＋ 邀請朋友」→「邀請好友」，或在好友名單按「邀請」。對方畫面會跳出邀請，按「加入」就進到你的房間。好友在房間裡的話，你也可以直接按「加入」。
- 好友身分存在瀏覽器裡：換電腦、換瀏覽器或清除瀏覽資料，會變成新的身分。和朋友都用上面的線上版網址玩。

## 下載到電腦玩

1. 按本頁綠色的 **Code → Download ZIP**，然後解壓縮。
2. 雙擊裡面的 `index.html`。

- 需要連網：遊戲引擎、天空和字型是從網路 CDN 載入的。
- 建議使用 Chrome 或 Edge。
- 筆電有獨立顯卡（NVIDIA）的話，到 Windows **設定 → 系統 → 顯示器 → 圖形**，把瀏覽器設成「高效能」，會順很多。遊戲右下角 FPS 旁會顯示目前用的是哪張顯卡。

## 操作

| 按鍵 | 動作 |
|---|---|
| WASD | 移動 |
| SHIFT | 衝刺（不會掉下邊緣） |
| C | 蹲下（沒有腳步聲）；衝刺中按 = 滑鏟 |
| SPACE | 跳；對著矮牆按 = 攀爬翻越 |
| 滑鼠左鍵 / 右鍵 | 開火 / 開鏡 |
| R | 換彈 |
| 1–6 / Q | 切換武器 / 快速切換 |
| F | 擒拿 |
| E | 互動、拾取、佔領 |
| W / S（在梯子上） | 爬梯子 |
| F1–F5 | 預約配裝 A–E（下次重生時換上） |
| TAB | 計分板 |
| ESC | 暫停、設定 |

在大廳或房間按「倉庫」可以編輯 5 組配裝（A–E）。

## 給開發者

- 原始碼在 `src/`，執行 `sh src/build.sh` 會合併成根目錄的單檔 `index.html`。
- `node tools/check.mjs` 做自動檢查（需要 `npm install`，會使用本機的 Chrome）。
- 開發紀錄在 `PROGRESS.md`，重大版本的單檔保存在 `versions/`。

這是非官方的同好作品，與《特種部隊 2》的開發商和營運商無關。
