# SF2 Tactical Prototype

在瀏覽器裡玩的戰術 FPS，靈感來自《特種部隊 2》。可以單人對戰 AI Bot，也可以和朋友連線對戰（團隊死鬥）。有 7 張地圖和 31 把槍，支援團隊死鬥、回合殲滅、奪取、佔領等模式。

## ▶ 線上試玩

**https://weiweiweiweiweiweiweiwei.github.io/sf2-tactical-prototype/**

打開網址 → 在房間選地圖、人數、模式 → 按「出發」→ 點畫面鎖定滑鼠就能開始。

## 和朋友連線對戰

**開房間的人：**
1. 在房間的「線上對戰」區塊輸入暱稱，勾選「出發時開放線上房間」，賽制選**團隊死鬥**，按「出發」。
2. 進入戰場後按 ESC →「複製邀請連結」，傳給朋友。房間代碼也會顯示在畫面右下角的 FPS 旁邊。

**加入的人**，三種方式都可以：
- 直接點邀請連結。
- 在房間的「線上對戰」區塊輸入 5 碼房間代碼，按「加入」。
- 從房間列表按「加入」。

加入後會取代同一隊的一個 Bot，可以中途加入。說明：

- **對戰不會暫停**：連線中按 ESC 或切到別的視窗，對戰都照常進行。
- **房主離開，對戰就結束**：開房間的人是房主，大家的遊戲資料直接和房主的電腦連線，不經過伺服器。
- **大部分家用網路可以直接連**：部分手機熱點、公司或學校網路會擋直連，這時會顯示「無法和房主建立直接連線」，換個網路再試。
- **最多 8 人**。目前只支援團隊死鬥；手榴彈和掉槍還沒同步。

自己想先測試的話：同一個瀏覽器開兩個分頁，一個開房間，另一個在大廳輸入代碼加入即可。

## 下載到電腦玩

1. 按本頁綠色的 **Code → Download ZIP**，然後解壓縮。
2. 雙擊裡面的 `index.html`。

- 需要連網：遊戲引擎、天空和字型是從網路 CDN 載入的。
- 建議使用 Chrome 或 Edge。
- 筆電有獨立顯卡（NVIDIA）的話，到 Windows **設定 → 系統 → 顯示器 → 圖形**，把瀏覽器設成「高效能」，會順很多。遊戲右下角 FPS 旁會顯示目前用的是哪張顯卡。

## 操作

| 按鍵 | 動作 |
|---|---|
| WASD | 移動 |
| SHIFT | 衝刺（不會掉下邊緣） |
| C | 蹲下（沒有腳步聲）；衝刺中按 = 滑鏟 |
| SPACE | 跳；對著矮牆按 = 攀爬翻越 |
| 滑鼠左鍵 / 右鍵 | 開火 / 開鏡 |
| R | 換彈 |
| 1–6 / Q | 切換武器 / 快速切換 |
| F | 擒拿 |
| E | 互動、拾取、佔領 |
| W / S（在梯子上） | 爬梯子 |
| F1–F5 | 預約配裝 A–E（下次重生時換上） |
| TAB | 計分板 |
| ESC | 暫停、設定 |

在房間按「倉庫」可以編輯 5 組配裝（A–E）。

## 給開發者

- 原始碼在 `src/`，執行 `sh src/build.sh` 會合併成根目錄的單檔 `index.html`。
- `node tools/check.mjs` 做自動檢查（需要 `npm install`，會使用本機的 Chrome）。
- 開發紀錄在 `PROGRESS.md`，重大版本的單檔保存在 `versions/`。

這是非官方的同好作品，與《特種部隊 2》的開發商和營運商無關。
