## Background
In the wake of the mass Frontier Migration into the Outlands, regional conflicts and land - grabs created a demand for inexpensive firearms. The Mozambique shotgun (named for an execution technique with a similar, triangular spread) served that function for Pilots in the Frontier and a new model was soon being mass-produced for civilian use. The result is a firearm with a small magazine and minimal stopping power - while useful for self - defense, a standard Mozambique will require modifications (or a lot of luck) to be useful in a real fight.
