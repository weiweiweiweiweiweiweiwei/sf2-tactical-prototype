## 3. RPM 回歸公式驗證

公式：RPM ≈ 8.5235 × 射速等級 + 15.125（最小平方法）

| 樣本 | 類型 | 射速等級 | 實際 RPM | 預測 | 殘差 | 留一法預測 | 留一法誤差 |
|---|---|---|---|---|---|---|---|
| M14EBR | 精確射手步槍 | 23 | 214 | 211.2 | +2.8 | 167.5 | **+46.5** |
| AK-103 | 突擊步槍 | 61 | 529 | 535.1 | −6.1 | 537.1 | −8.1 |
| SG 551 | 突擊步槍 | 72 | 620 | 628.8 | −8.8 | 633.6 | −13.6 |
| FAMAS | 突擊步槍 | 78 | 692 | 680.0 | +12.0 | 669.8 | +22.2 |

- **統計**：n = 4，射速等級範圍 23–78，RPM 範圍 214–692。
  - R² = 0.998，MAE = 7.44，RMSE = 8.18，最大絕對殘差 12.04。
  - 殘差標準誤（自由度 2）= 11.56。
  - 留一法 MAE = 22.6，RMSE = 26.9。
- **R² 被灌水了**：M14EBR 是孤立在低端的高槓桿點。拿掉它只剩 3 把步槍時，斜率從 8.52 變成 9.43（差 11%），預測它自己時誤差 46.5 RPM。
- **加入 G36C（wiki 寫 782）的話，R² 降到 0.796**。它偏離回歸線 221 RPM，而且 wiki 自己的 DPS 推回去約 545，判定是 wiki 的錯誤，所以排除。
- **各武器類型的樣本數**：

| 類型 | 樣本數 | 結論 |
|---|---|---|
| 突擊步槍 | 3 | 唯一能評估的類型，留一法誤差在 −8 到 +22 之間 |
| 精確射手步槍 | 1 | 無法評估 |
| 衝鋒槍 | 0 | P90（86）、MP5K（92）**超出擬合範圍** |
| 機槍 | 0 | 等級 64–67 雖然在數字範圍內，但沒有證據顯示機槍和步槍遵循同一條線 |
| 狙擊、手槍、霰彈槍 | 0 | 射速條顯示 0，**公式不適用** |

- **使用限制**：只能拿來推估射速等級 61–78 的突擊步槍，必須標成 estimated，誤差 ±25 RPM（留一法）。而且輸入資料本身是 unverified。
  - 目前推估的有：M4A1 637、K2 612、HK417 586。
  - 衝鋒槍、機槍、狙擊、手槍、霰彈槍一律不推估。
