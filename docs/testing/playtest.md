# 真人雙機測試清單

**怎麼用**：兩台電腦（你和朋友），各自用 Chrome 打開 GitHub Pages 的遊戲連結。每一項只要記「✅ 正常／⚠️ 怪怪的／❌ 壞掉」，再加一句描述就好。沒把握的項目，錄一段 10 秒的影片最有幫助（Win + Alt + R）。

開始前先記下：
- 兩台電腦的顯示卡
- 網路（Wi-Fi 或有線、同一個地方或不同城市）
- 遊戲右上角的 FPS
- 測試日期

## 1. 連線（10 分鐘）
- [ ] 你建房，把邀請連結傳給朋友。朋友點開後，幾秒內進到房間？
- [ ] 朋友改用 6 碼房號加入，也能成功嗎？
- [ ] 你改地圖和模式，朋友那邊有同步嗎？
- [ ] 按開始後，兩邊一起倒數、一起進場嗎？
- [ ] 打完一場，兩邊會一起回到房間嗎？第二場能直接開嗎？
- [ ] 朋友中途關掉分頁再用連結回來，能加入進行中的對戰嗎？
- [ ] 整場有沒有斷線、卡住不動、或角色瞬移？發生在第幾分鐘？

## 2. 移動（5 分鐘）
- [ ] 走、跑（Shift）、蹲（C）、跳（Space）、滑鏟，手感順嗎？
- [ ] 從朋友的畫面看你：走路平順，還是一頓一頓、會瞬移？
- [ ] 上下樓梯、爬梯子、跳上箱子，有沒有卡住？

## 3. 射擊手感（10 分鐘，用 M4A1、M200、P90 各打一陣）
- [ ] 腰射和開鏡：準心和子彈落點一致嗎？
- [ ] 連射的後座力：太飄、太穩，還是剛好？
- [ ] 換彈（R）和切槍（1、2、Q）：動作和聲音對得上嗎？
- [ ] 狙擊開鏡、拉栓：節奏對嗎？
- [ ] 槍聲：近距離有力嗎？遠處朋友開槍，聽得出方向和距離嗎？

## 4. 命中回饋（10 分鐘，互打）
- [ ] 你確定瞄準朋友開槍時，有命中提示（準心變化、命中音）嗎？
- [ ] 有沒有「明明打到卻沒算」或「躲到牆後還被打死」？大概多常發生？
- [ ] 爆頭、擊殺：徽章、擊殺訊息、音效都有出現嗎？
- [ ] 死亡後幾秒重生？重生點會不會太近敵人？

## 5. 流暢度（全程留意）
- [ ] FPS 大概多少？有沒有突然掉很多？在哪張地圖、什麼場面？
- [ ] 有沒有畫面閃爍、黑塊、材質消失？
- [ ] 打完一整場後，整體感覺：想再玩一場嗎？最想改進的是哪一點？

## 回報
把這份清單打勾，附上錄影，貼回對話就可以。最重要的三題：
1. 有沒有斷線或卡頓？
2. 互打時，命中算得準不準？
3. 想不想再玩？
